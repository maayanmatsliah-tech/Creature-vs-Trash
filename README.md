# Trash vs. Marine Life Classifier

A CNN-based image classifier that distinguishes ocean trash from marine life, as a step toward automated debris detection.

🔗 **Live Demo:** *Coming soon*

---

## Dataset
Combined from two Kaggle sources — the [Sea Animals Dataset](https://www.kaggle.com) (~19,000 images) and the [UW Garbage Debris Dataset](https://www.kaggle.com/datasets/siddharth2305ego/underwater-garbagedebris) (~5,130 images) — plus an original trash dataset.

| Split | Sea Animals | Trash | Total |
|-------|-------------|-------|-------|
| Train | 15,214 | 5,575 | 20,789 |
| Val   | 3,804  | 1,394 | 5,198  |
| **Total** | **19,018** | **6,969** | **25,987** |

Class ratio is ~3:1 (sea animals : trash), improved from an original 10:1 by adding the UW Garbage Debris dataset.

---

## Model
- **Base model:** ResNet-18 (pretrained on ImageNet), fine-tuned end-to-end with a 2-class output layer
- **Framework:** PyTorch

| Parameter | Value |
|-----------|-------|
| Optimizer | SGD (momentum=0.9) |
| Learning rate | 0.001 (StepLR, step=7, gamma=0.1) |
| Batch size | 4 |
| Epochs | 10 |
| Hardware | NVIDIA T4 GPU (Google Colab) |

---

## Results
**Best validation accuracy: 99.81%** (training time: 74m 22s). Full per-epoch loss/accuracy log, plus a classification report and confusion matrix (via `scikit-learn`/`seaborn`), are generated in the notebook.

> An earlier run on the original 10:1 imbalanced dataset scored ~46% accuracy, which is what motivated the rebalancing above.

## How to Run

```
pip install -r requirements.txt
```

1. Organize your dataset:
```
datasets/
├── train/{sea_animals,trash}/
└── val/{sea_animals,trash}/
```
2. Open `ocean_life_vs_trash.ipynb` in Google Colab, update `data_dir`, and run all cells
3. Trained weights are saved to `model.pt` in your dataset directory

### Inference
```python
import torch
from torchvision import models, transforms
from PIL import Image

model = models.resnet18()
model.fc = torch.nn.Linear(model.fc.in_features, 2)
model.load_state_dict(torch.load('model.pt'))
model.eval()

transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
])

img_tensor = transform(Image.open('your_image.jpg')).unsqueeze(0)
with torch.no_grad():
    pred = torch.argmax(model(img_tensor), 1).item()
    print(['sea_animals', 'trash'][pred])
```
